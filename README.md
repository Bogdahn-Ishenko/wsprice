# WSPrice

Клиентское React-приложение для поиска производителей автозапчастей, аналогов и предложений Favorit Parts.

## Как работает поиск

1. Введите ключ доступа и артикул. После ввода артикула приложение запрашивает товары и формирует список уникальных производителей.
2. Выберите производителя. Приложение повторно запрашивает API с артикулом, брендом и `analogues=on`.
3. Результаты показывают название, производителя, цену и суммарный остаток по складам.

Состояния загрузки, пустые ответы, сетевые ошибки и ошибки API отображаются в интерфейсе. Запросы к производителям срабатывают с небольшой задержкой после ввода и отменяются при изменении поисковых данных.

## Технологии

- React
- Redux Toolkit и React Redux
- Vite
- Favorit Parts API (`http://api.favorit-parts.ru/hs/hsprice/`)

Python и серверная часть не используются. Ключ передаётся непосредственно из браузера и не сохраняется.

> API вызывается напрямую из браузера. Для работы необходим доступ к API и разрешённые на его стороне CORS-запросы. Если сервер API запрещает CORS, потребуется согласованный с владельцем API прокси.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```
